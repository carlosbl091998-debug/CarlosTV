# Validación móvil de Magis

Esta rama prueba primero una versión móvil actual sin modificar sus protecciones. La validación exige: paquete `com.msandroid.mobile`, firma verificable, instalación correcta, lanzamiento en Android 16 y proceso vivo después de 47 segundos. También se guardan captura, árbol UI y logcat para detectar diálogos de actualización o cierres.
