# Carlos TV v0.1

Aplicación Android tipo WebView que abre `https://rojadirectaa.net/` dentro de una interfaz propia.

## Funciones incluidas

- JavaScript, almacenamiento web y cookies de terceros.
- Reproducción de video HTML5 y modo de pantalla completa.
- Navegación con el botón Atrás de Android.
- Indicador de carga y botón para reintentar cuando falla la conexión.
- Bloqueo de ventanas automáticas sin interacción del usuario.
- Compatibilidad desde Android 6.0 (API 23).

La aplicación no descarga ni extrae transmisiones, no elimina protecciones y no controla el contenido del sitio externo. Úsala únicamente para contenido al que tengas acceso legítimo.

## Obtener el APK desde el celular

1. Abre la pestaña **Actions** del repositorio.
2. Entra al flujo **Compilar APK** más reciente.
3. En **Artifacts**, descarga `CarlosTV-v0.1-debug`.
4. Abre el ZIP descargado y toca `CarlosTV-v0.1-debug.apk`.
5. Si Android lo solicita, permite temporalmente **Instalar apps desconocidas** para tu navegador o gestor de archivos.

El APK de prueba queda disponible durante 30 días después de cada compilación. Cada cambio enviado a la rama `main` crea uno nuevo automáticamente.
